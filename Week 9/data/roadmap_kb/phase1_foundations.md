# Phase 1 — Foundations (Weeks 1–3)

## Week 1 — Python Fundamentals
Topics: Variables & data types, Control flow (if / for / while), Functions & scope, Lists, dicts & sets, File I/O basics.
Deliverable: Mini project — To-Do List.

## Week 1 (Add-on) — Secure Coding & AI-Assisted Development
Rationale: most candidates now write code with AI assistance (Copilot/ChatGPT), so the differentiating skill is reviewing, securing, and validating generated code, not just producing it.
Topics: Code review mindset for auditing AI-generated code for correctness and safety; input validation & sanitization; secrets management (environment variables, .env files, never hardcoding credentials/API keys); safe error handling (avoiding broad except blocks that silently swallow failures); dependency awareness (verifying suggested libraries before installing).
Deliverable: Code audit exercise — given a snippet of AI-generated code with planted vulnerabilities, candidates identify and fix the issues.

## Week 2 — Python for Data & Intro Statistics
Topics: NumPy & Pandas, Matplotlib / Seaborn for visualisation, Descriptive statistics (mean, median, std), Probability distributions, Correlation & covariance.
Deliverable: EDA notebook on a sample dataset.

## Week 3 — SQL Essentials
Topics: SELECT, WHERE, ORDER BY; INNER / LEFT / RIGHT / FULL OUTER JOINs; GROUP BY & aggregate functions; Subqueries & CTEs; Window functions (ROW_NUMBER, RANK, LAG).
Deliverable: SQL case study — Student Result Analysis.
